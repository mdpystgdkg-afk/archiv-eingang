# archiv-eingang

Öffentliche Startseite und Datenschutzerklärung für ein privates Google-Apps-Script, das Dokumente in ein persönliches Archiv übernimmt.

Google verlangt für eigene Cloud-Projekte im Status „In Produktion“ eine öffentlich erreichbare Startseite und Datenschutzerklärung. Beides liegt hier und wird über GitHub Pages ausgeliefert:

- Startseite: https://mdpystgdkg-afk.github.io/archiv-eingang/
- Datenschutz: https://mdpystgdkg-afk.github.io/archiv-eingang/datenschutz.html

Das Skript selbst ist nicht öffentlich.

> **Hinweis:** Dieses Repo nicht löschen oder umbenennen – sonst funktioniert die Google-Anmeldung des Skripts nicht mehr.
